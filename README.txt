NOCTURNE / LAB

ВЕРСИЯ 2 — АНИМАЦИЯ И WALLPAPER ENGINE
- dist\NOCTURNE Wallpaper v2.exe — новый редактор с аппаратно ускоряемым Canvas-рендерингом в Chromium/Edge.
- Для волн и перспективных сеток доступны интерактивные точки изгиба: выберите слой, нажмите «Добавить точку» и кликните по холсту либо используйте двойной клик. Точки можно перетаскивать мышью.
- Нижний таймлайн сохраняет полное состояние сцены в ключевых точках. Между ключами числа, цвета, положение и геометрия интерполируются автоматически; правый клик по маркеру удаляет ключ.
- «+ Спектр» добавляет аудиовизуализатор в режимах «столбцы», «линия» и «радиальный». В браузере работает демонстрационная анимация, в Wallpaper Engine используются 64 частотные полосы каждого канала.
- «+ Часы» добавляет живые часы и дату: 12/24 часа, секунды, форматы даты, локаль, системный шрифт, начертание, размер, интервал, цвета и свечение.
- Кнопка «Wallpaper Engine» создаёт ZIP с автономными index.html и project.json. Распакуйте его в отдельную папку и перетащите index.html в Create Wallpaper.
- Ограничение 30/60 FPS находится рядом с таймлайном и сохраняется в экспортируемый проект.

ИСХОДНИКИ И СБОРКА V2
- src\wallpaper-studio.base.html — исходный редактор первой версии.
- src\nocturne-features.js — точки сетки, таймлайн, спектр и экспорт Wallpaper Engine.
- src\WallpaperLauncher.cs — компактная .NET-обёртка, извлекающая редактор в %LOCALAPPDATA%\NocturneLab и открывающая его в браузере.
- build-wallpaper.ps1 — собирает src\wallpaper-studio.html и dist\NOCTURNE Wallpaper v2.exe штатным компилятором .NET Framework 4.

Сборка:

.\build-wallpaper.ps1

ФАЙЛЫ
- NOCTURNE Wallpaper.exe — автономный редактор и генератор обоев со встроенной HTML-страницей.
- NOCTURNE Icon.exe — автономный редактор прозрачных многомасштабных значков ICO со встроенной HTML-страницей.
- game4art-logo.svg — пример векторного слоя.
- apply-nocturne-theme.ps1 — применение готовых обоев, тёмной темы и системного акцента.
- start-theme-setup.cmd — запуск графического окна настройки темы двойным щелчком.

ОБОИ
Запустите NOCTURNE Wallpaper.exe. Встроенная страница автоматически откроется в браузере по умолчанию. Проекты сохраняются кнопкой «Сохранить проект», готовое изображение — кнопкой «Экспорт PNG».

ЗНАЧКИ
Запустите NOCTURNE Icon.exe. Редактор поддерживает слои, SVG и растровые изображения, контуры, заливки, градиенты, свечение, точки изгиба и альфа-канал фона от 0 до 100%.

«Экспорт ICO» создаёт один файл с PNG-кадрами 16, 24, 32, 48, 64, 128 и 256 пикселей. Благодаря этому Проводник Windows выбирает подходящий кадр при изменении масштаба.

ТЕКСТ И ФИРМЕННЫЕ ЗНАКИ
В редакторе значков кнопка «+ Текст» создаёт отдельный текстовый слой. Доступны шрифт, насыщенность, размер, интервал, обводка, заливка, градиент, свечение, прозрачность и трансформация.

- nocturne-wallpaper-mark.svg / .ico — переплетённый ленточный знак N + w для студии обоев.
- nocturne-icon-mark.svg / .ico — переплетённый ленточный знак N + i для ICO-студии.
- nocturne-marks-preview.png — общий предпросмотр двух эмблем.

Обе версии ICO содержат размеры 16, 24, 32, 48, 64, 128 и 256 пикселей и сохраняют прозрачный фон. SVG можно импортировать обратно в редактор.

ТЕМА WINDOWS
Запустите start-theme-setup.cmd и выберите файл обоев, размещение, акцентный цвет и режим прозрачности интерфейса.

Альтернативный запуск из PowerShell:

.\apply-nocturne-theme.ps1 -WallpaperPath "C:\полный\путь\к\обоям.png" -AccentColor "#FFFFFF"

Параметр -DisableTransparency отключает прозрачность интерфейса Windows. При запуске без пути открывается графическое окно; параметр -NoGui оставляет командный режим.

Перед изменениями создаётся резервная копия в %LOCALAPPDATA%\NocturneLab. Управляемые административные политики не изменяются: если они блокируют обои, окно сообщит об этом и применит только разрешённые параметры текущего пользователя.
АВТОНОМНЫЕ ПРИЛОЖЕНИЯ
Обе HTML-страницы и их favicon-SVG встроены внутрь соответствующих EXE. При запуске актуальная копия тихо разворачивается в %LOCALAPPDATA%\NocturneLab и открывается в браузере. Файлы рядом с EXE для работы не требуются.
СОВМЕСТИМОСТЬ
- Windows 10 и Windows 11, 64-разрядные и 32-разрядные пользовательские сеансы.
- Штатный Windows PowerShell 5.1; PowerShell 7 поддерживается в Windows при запуске GUI с ключом -STA.
- Пути с пробелами и кириллицей; сам скрипт записан в UTF-8 с BOM для корректного чтения Windows PowerShell 5.1.
- PNG, JPG, JPEG и BMP для системных обоев.
- Повторный запуск в одной PowerShell-сессии не конфликтует с уже загруженным Win32-типом.
- Изменения рассылаются оболочке Windows через WM_SETTINGCHANGE и дублируются штатным UpdatePerUserSystemParameters.

Скрипт не требует прав администратора и меняет только доступные параметры текущего пользователя. Политики домена, организации и локального администратора определяются и остаются без изменений.

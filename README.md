## Возможности
- Волны и перспективные сетки с интерактивными линиями изгиба: длина, угол, сторона воздействия, сила и плавность затухания.
- Линейная интерполяция между ключевыми кадрами; опциональная галка «Плавно» включает smoothstep.
- Ключи можно перетаскивать по шкале и удалять правой кнопкой; изменение длины таймлайна пропорционально масштабирует позиции всех ключей.
- Спектр в режимах «столбцы», «линия» и «радиальный»: сектор, угол, автоусиление, ручное усиление и шумовой порог.
- Часы и дата с системными и загружаемыми TTF, OTF, WOFF и WOFF2 шрифтами.
- Сферическая сетка-глобус с широтами, долготами, перспективой и автовращением.
- Пустой стартовый холст и нейтральные параметры новых элементов.
- Редактируемые числовые значения у всех ползунков.
- Кнопка «В центр» и привязка к центральным осям при перетаскивании с Shift.
- Оптимизированный 4K-runtime: кэш статичных слоёв, пакетный Path2D и ограничение дорогого свечения.
- Нативный холст **1260×2800** и безопасная зона для Nothing Phone (3).
- Адаптивное заполнение экрана без растягивания геометрии: cover, contain или stretch.
- Переработанный интерфейс с акцентом RGB 0, 233, 255 и встроенным шрифтом Oxanium, который не требует установки в системе.
- Собственные разрешения холста с сохранением пользовательских пресетов.
- Отдельный экспорт **Android Scene** создаёт нативный пакет WPE Scene: фоновая анимация записывается строго от первого до последнего ключа, а спектр остаётся живым GPU-шейдером и не запекается в видео. Видео упаковывается как WPE-текстура, а пути внутри `scene.pkg` нормализуются для мобильного конвертера.

## Wallpaper Engine
Поле имени в шапке задаёт имя проекта, JSON, PNG, ZIP и заголовок обоев в Wallpaper Engine. «WPE проект» сохраняет редактируемую папку, а «WPE ZIP» создаёт переносимый архив. Оба варианта содержат автономные `index.html`, `project.json`, автоматически снятый `preview.png`, `APPLY-WALLPAPER.cmd` и `INSTALL-PUBLISH.cmd`.

- `APPLY-WALLPAPER.cmd` сразу применяет обои и запускает Wallpaper Engine из его собственной рабочей папки, поэтому кэш шейдеров не появляется на рабочем столе.
- `INSTALL-PUBLISH.cmd` копирует проект в `wallpaper_engine\projects\myprojects`, после чего его можно открыть в редакторе и отправить через **Workshop → Share wallpaper on Workshop**.
- Web-проекты предназначены для настольного WPE: Android их не принимает. Для телефона нажмите **Android Scene**, распакуйте ZIP, запустите `INSTALL-ANDROID.cmd`, затем выберите установленную Scene-версию в WPE и нажмите **Send to Mobile Device**. В том же ZIP лежит готовый `DIRECT-MOBILE.mpkg`: его можно перенести на телефон и открыть в Wallpaper Engine Android напрямую, если отправка с ПК недоступна.

Перед сохранением старые проекты автоматически нормализуются: каждый ключ содержит все актуальные слои, поэтому поздно добавленные спектр, часы и другие элементы не исчезают между ключами.

В свойствах готовых обоев доступны полноценные разделы:
- аудио: канал, входное и автоматическое усиление, чувствительность, шумовой порог, атака, спад и баланс НЧ/ВЧ;
- эквалайзер: режим, число полос, ширина, высота, положение, свечение, отражение и движение без сигнала;
- экран: режим заполнения, качество рендера и ограничение FPS.

Аудио обрабатывается по 128 значениям Wallpaper Engine: 64 частотных диапазона на левый и 64 на правый канал. Runtime также принимает моно, typed arrays и раздельные каналы, а watchdog повторно подключает listener после сна, перезапуска или пересоздания web-контекста. Используются RMS-агрегация диапазонов, мягкий шумовой порог, независимые атака/спад и стабилизированное автоусиление.

Физическое устройство перехвата выбирается глобально в Wallpaper Engine: **Настройки → Основные → Медиа → Устройство записи аудио**.

> Android Scene-экспорт не записывает декоративное движение спектра в ролик. Фоновая анимация воспроизводится видео-текстурой, а визуализатор строится нативным шейдером WPE из `g_AudioSpectrum16Left/Right`. Доступность живого аудио на телефоне зависит от версии Android-клиента Wallpaper Engine и способа воспроизведения звука.

## Сборка

Готовая версия: `dist\NOCTURNE-Wallpaper-Studio.exe`.

Для пересборки запустите:

```powershell
.\build-wallpaper.ps1
```

Скрипт генерирует src\wallpaper-studio.html из базового редактора и расширений, после чего встраивает страницу в EXE штатным компилятором .NET Framework 4.

## Структура
- src\wallpaper-studio.base.html — базовый интерфейс редактора.
- src\nocturne-features.js — функции v2 и runtime экспортируемых обоев.
- src\WallpaperLauncher.cs — компактная Windows-обёртка.
- src\assets\Oxanium-wght.ttf — встраиваемый интерфейсный шрифт под SIL Open Font License.
- tools\repair-wallpaper-project.js — восстановление и оптимизация старых проектов.
- build-wallpaper.ps1 — воспроизводимая сборка EXE.

## Совместимость
- Современные браузеры на Windows, Linux и macOS — через автономный HTML.
- Windows 10 и Windows 11 — через готовый EXE-лаунчер.
- Windows PowerShell 5.1 или PowerShell 7 нужен только для локальной пересборки EXE.
- Экспорт в Wallpaper Engine Web wallpapers выполняется из браузерной версии на любой ОС; запуск в Wallpaper Engine зависит от поддерживаемой платформы самого WPE.

## Возможности
- Волны и перспективные сетки с интерактивными точками изгиба, направлением и ограничением по осям.
- Линейная интерполяция между ключевыми кадрами; опциональная галка «Плавно» включает smoothstep.
- Ключи можно перетаскивать по шкале и удалять правой кнопкой; изменение длины таймлайна пропорционально масштабирует позиции всех ключей.
- Спектр в режимах «столбцы», «линия» и «радиальный»: сектор, угол, автоусиление, ручное усиление и шумовой порог.
- Часы и дата с системными и загружаемыми TTF, OTF, WOFF и WOFF2 шрифтами.
- Сферическая сетка-глобус с широтами, долготами, перспективой и автовращением.
- Пустой стартовый холст и нейтральные параметры новых элементов.
- Редактируемые числовые значения у всех ползунков.
- Кнопка «В центр» и привязка к центральным осям при перетаскивании с Shift.
- Оптимизированный 4K-runtime: кэш статичных слоёв, пакетный Path2D и ограничение дорогого свечения.
- Нативный холст **1260×2800** и безопасная зона для Nothing Phone (3).
- Адаптивное заполнение экрана без растягивания геометрии: cover, contain или stretch.

## Wallpaper Engine
Поле имени в шапке задаёт имя проекта, JSON, PNG, ZIP и заголовок обоев в Wallpaper Engine. Кнопка «Wallpaper Engine» создаёт ZIP с автономными `index.html`, `project.json` и `APPLY-WALLPAPER.cmd`. Сначала распакуйте ZIP целиком, затем запустите `APPLY-WALLPAPER.cmd`; либо выберите `index.html` через «Открыть офлайн-обои» в Wallpaper Engine.

Перед сохранением старые проекты автоматически нормализуются: каждый ключ содержит все актуальные слои, поэтому поздно добавленные спектр, часы и другие элементы не исчезают между ключами.

В свойствах готовых обоев доступны полноценные разделы:
- аудио: канал, входное и автоматическое усиление, чувствительность, шумовой порог, атака, спад и баланс НЧ/ВЧ;
- эквалайзер: режим, число полос, ширина, высота, положение, свечение, отражение и движение без сигнала;
- экран: режим заполнения, качество рендера и ограничение FPS.

Аудио обрабатывается по 128 значениям Wallpaper Engine: 64 частотных диапазона на левый и 64 на правый канал. Используются RMS-агрегация диапазонов, мягкий шумовой порог, независимые атака/спад и стабилизированное автоусиление.

Физическое устройство перехвата выбирается глобально в Wallpaper Engine: **Настройки → Основные → Медиа → Устройство записи аудио**.

> Wallpaper Engine для Android поддерживает аудиовизуализаторы после выдачи приложению разрешения на запись аудио. Однако NOCTURNE экспортирует Web-проект, а мобильная передача WPE рассчитана прежде всего на Scene/Video. Для Web-версии на Nothing Phone (3) доступен режим «Движение без аудиосигнала».

## Сборка

Готовая версия: `dist\NOCTURNE-Wallpaper-Studio.exe`.

Для пересборки запустите:

```powershell
.\build-wallpaper.ps1
```

Скрипт генерирует src\wallpaper-studio.html из базового редактора и расширений, после чего встраивает страницу в EXE штатным компилятором .NET Framework 4.

## Структура
- src\wallpaper-studio.base.html — базовый интерфейс редактора.
- src\nocturne-features.js — функции v2 и runtime экспортируемых обоев.
- src\WallpaperLauncher.cs — компактная Windows-обёртка.
- tools\repair-wallpaper-project.js — восстановление и оптимизация старых проектов.
- build-wallpaper.ps1 — воспроизводимая сборка EXE.

## Совместимость
- Современные браузеры на Windows, Linux и macOS — через автономный HTML.
- Windows 10 и Windows 11 — через готовый EXE-лаунчер.
- Windows PowerShell 5.1 или PowerShell 7 нужен только для локальной пересборки EXE.
- Экспорт в Wallpaper Engine Web wallpapers выполняется из браузерной версии на любой ОС; запуск в Wallpaper Engine зависит от поддерживаемой платформы самого WPE.
